# PocketGrader Project Challenges & Resolved Issues

## Phase 1: Document Ingestion & Parsing
* **Scanned/Messy PDF Layouts:** Raw text extracted from PDFs had inconsistent spacing, headers, footers, and page numbers mixed into text.
* **PyMuPDF Warning:** Using `import fitz` triggered deprecation warnings. Resolved by updating imports to `import pymupdf as fitz`.

## Phase 2: Text Chunking & Vector Database (ChromaDB)
* **Chunk Slicing Strategy:** Settled on 500-character chunks with 50-character overlaps to balance context precision.
* **Database Resetting:** Created manual deletion command (`Remove-Item -Recurse -Force ./chroma_db`) to clear local vector storage during development testing.

## Phase 3: Past Paper Structure Parsing & Pydantic Schemas
* **Missing Ollama Model (404 Error):** Defaulting to `llama3.2` failed because it wasn't downloaded. Switched model target to `gemma3:4b`.
* **Empty JSON Output (`{}`):** Instructing Ollama to output standard `"json"` returned empty objects. Resolved by passing `ExamSkeleton.model_json_schema()` directly into Ollama's `format` parameter.
* **Prompt Truncation:** Truncating text to 4,000 characters cut off pages 2–4 of past papers. Expanded input buffer to 12,000 characters.
* **Model Text Hallucinations:** AI generated synthetic essay questions instead of structural slots. Resolved by stripping description fields from Pydantic schemas, setting `temperature=0.0`, and enforcing strict extraction rules in system prompt.
* **Schema Attribute Mismatch:** Test scripts crashed looking up `q.marks` instead of `q.total_marks`. Updated print script to match schema attributes.
